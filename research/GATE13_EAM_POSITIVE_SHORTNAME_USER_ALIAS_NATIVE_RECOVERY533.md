## Exact native call chain

1. **Creation time:** Original `0x5CE660..0x5CE695` copies signed `DBRPlayer+0x72` to type2 descriptor+8. Current port after PR620/621 has an *immutable* `verified_native_association_word_at_creation` in recognized producer→pending→delivered→internal-save records. There is no permission to infer that word from today's mutable `player.club_id` for legacy records.
2. **Display time:** `0x5CE715..0x5CE782` formats the current DBRPlayer first-initial/surname via `0x417AE0`. Descriptor+8 < 0 produces only `<T+P>%s<T->` (existing source-closed negative branch). For descriptor+8 >= 0, original indexes the club array using signed word times 680 bytes, calls club display `0x40DA70`, takes global language pointer `0x9844D8`, and formats exact `<T+P>%s<T-> @ <T+C>%s %s<T->`.
3. **Distinct original short-name accessor:** `0x40DA50` calls shared optional override `0x403600`, then falls back to `[DBRClub+0x08]`, the original full club name. **But the actual EAM formatter calls `0x40DA70`:** if the same override returns NULL it dereferences `[DBRClub+0x0C]`, the original short name. This is the material original boundary: the EAM must not substitute the long full name.
4. **Override is tied to a registered actual human, not any AI manager:** `0x403600` calls `0x4037B0`, which calls `0x4139E0` on the live user registry. `0x4139E0→0x4139F0` traverses `DBTUsers+0x9CC` and compares club identifier `[club+0x04]` to each registered `DBRUser+0x5B4+0x04`. If matched, `0x403850` calls `0x413B40` to retrieve the matching registered user, then `0x42C6D0` returns the `DBRUser+0xD0` caption buffer. Only **nonempty** caption bytes override the club short-name pointer; if empty, `0x403600` returns NULL. Native fresh user constructor `0x424F3F` sets `DBRUser+0xD0` byte zero. The current ordinary clean host does not expose a user alias input, and current internal save does not import original user aliases.
5. **Original source suffix:** `0x9844D8` is the verified main `English.idx[200]` → `English.str[19781]` = `Football Club`, already source-integrated Recovery532. Native short-name output uses the literal `<T+P>%s<T-> @ <T+C>%s %s<T->`.
