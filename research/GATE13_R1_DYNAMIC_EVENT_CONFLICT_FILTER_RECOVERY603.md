## Concrete source-to-runtime correction

Original new/dynamic match scheduling uses `0x615A60`. It clamps a requested source date-bucket index to **at least original current date+1** (global `0x9847FC` minus calendar owner relative offset +1), calls original `0x615890` on adjacent date buckets at `0x615A85` and, on conflict, retries forward from source conflict+2 at `0x615A97..0x615A9E`. When source conflict search reports no blocking match, it calls vtable+0x18, original `0x510300` event registry family and performs native head insertion, writing event+0x10 source slot index and event+0x04 next pointer at `0x615AC3..0x615ACB`. **15/15 source opcode sites** for this actual dynamic route independently matched original private PE and are in an opt-in test. The already merged PR694 source trace `0x615890→0x615790` establishes original neighbor filters: native existing event+8 **nonzero skips original virtual+0 entirely**, then native virtual+0x18 payload full match+0x44 bit6 **set** likewise skips it; only source-reached remaining events call original match v+0.

Previously live `PrimaryScheduleShadowState.first_dynamic_conflict_near` compared symbolic ClubRefs against **every** reconstructed neighbor, ignoring both source-required skip gates. This could displace a dynamic cup replay even when the original would skip the conflicting team on an already-linked or native bit6-excluded event. After an earlier replay/season transition, existing model fields may be UNKNOWN: silently counting those as available or as collisions was equally unsafe.

This branch now applies source-documented read precedence on the **real GameState dynamic cup replay insertion call path**:

- If the existing shadow entry is linked (`wrapper_link_state="linked"`), skip before consulting flags or symbolic clubs. This corresponds to original event+8 nonzero.
- If the link is `unknown`, raise before inserting a new replay. Unknown original runtime status cannot be represented by an invented source choice.
- If the original filter source bits are unknown (`payload_filter_bits is None`), raise before any side comparison. If native bit6 is set, skip the event exactly as `0x615790` does.
- If source v+0 event class is unqualified, fail closed. Only then perform the existing symbolic ClubRef comparison. This **last step is still an approximation** of native `0x510A80` and original source `0x4F2830` virtual effects, not full live native matching.
- Retain exactly the existing source-shaped current+1 day clamp, first-conflict three-bucket order, retry at conflict+2, and head-insert state. No source-unproved RNG, match results, UI, scoring or SaveLoad changes.

Code `reconstruction/primary_schedule_shadow.py` and `test_dynamic_primary_replay_order.py` now exercise actual `GameState._integrate_dynamic_cup_replay`, source known clear nodes, known linked-node skip before missing flag, known match flag6 skip, fail-closed unknown link/flags/vtable, earliest eligible adjacent bucket, and no state mutation after source errors.
