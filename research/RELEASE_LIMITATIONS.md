# Release Limitations

_Pre-release working list. This file is intentionally not a Gate-17 sign-off._

The Windows 11 modernization is not ready for release yet. The final
`gate17_release_readiness` audit deliberately refuses this document while it
still identifies itself as pre-release.

## Current unresolved release blockers

- Gate 13 remains the earliest incomplete validation gate. Repository schema 8
  now covers source-backed PMenu pixels, fresh Squad controls, the explicit
  source-accepted Squad container transition, League Fixtures grid art, the
  explicit source-resolved PMatchInfo popup/exit path, and the League Tables
  header. Schema 7 remains the last actual real-Windows receipt, so a fresh
  Windows 11/Tk schema-8 run and Gate-13 re-audit are still required. Remaining
  fail-closed presentation boundaries include ordinary Squad top-control
  pointer equivalence, the normal League Fixtures cell -> PMatchInfo linked
  context bridge, PMatchInfo owner-local child transforms, the surrounding
  application-owned management background, and PMenu keyboard equivalence.
- Gate 14 is work-ahead only. The original startup FMV identities and conversion
  path, reconstructed-event presentation feed, human-match adapter, bounded
  FastView semantic shell, fail-closed audio catalog boundary, and the
  seven-target FastView resource basename resolver are repository-verified.
  Original login/menu music and applicable sound resources are not yet
  integrated, the seven FastView resources still require exact source-path and
  placement proof from the private original-disc evidence, and a match is not
  yet recognizably presented in the original FM2001 style/workflow.
- Gate 15 has a committed work-ahead readiness audit at
  `research/GATE15_READINESS_AUDIT.md`, but it is not complete while Gates
  13-14 remain open. Several former fidelity items are already source-closed:
  persistent-injury availability, country transfer-window lifecycle, contract
  month normalization, autonomous contract category, Premier League FanFactor,
  and the DBRClub +0x1ED permanent-arrival lifecycle. The legacy chairman

  branches, due-transfer same-day fixture ordering, support-staff amount

  source-closed the special Cup controlled-participant category-1/category-2
  accounting helper and exact numeric 0x5DBCD0 paired-XI modifier, but that
  modifier's match-family caller/applicability remains fail-closed. Every
  remaining deterministic fallback or approximation must stay explicitly
  labeled and must be fixed, proven irrelevant, or intentionally accepted in
  the final Gate-15 audit.
- Gate 16 completion criteria are already prevalidated by committed work-ahead,
  including six deterministic synthetic seeds, destructive annual regeneration
  and save-growth soaks, five years of autonomous transfer churn, mixed
  shared-primary competition stress, and two independent canonical shipped-data

  Gate 16 is intentionally not marked complete while Gates 13-15 remain open.
  When those prerequisites close, the relevant full suite must be rerun and

  runtime.
- Gate 17 does not yet have a verified installable release archive, clean
  Windows 11 installation receipt, final gameplay receipts tied to one release
  commit, or a final non-pre-release limitations document.

## Final-review rule

Before release, replace this working list with the actual limitations that
remain intentionally accepted after Gates 13 through 16 are audited. Do not
remove a limitation merely to satisfy the release tool. The final document
must describe the shipped build accurately, and the final Windows release audit
must run against the same clean repository commit and archived build recorded
in its evidence receipts.
