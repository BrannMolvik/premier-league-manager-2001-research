- `0x418220` performs an actual TWO-WAY exchange: original player subobject+0x248 low5 BYTE+3 and low4 BYTE+4 are first retrieved via native getters 0x4EA3C0/0x4EA3D0. ## Original conditional starter external count effect

After common status methods, starter 0x4182F0 calls 0x417340. When that returns AL nonzero, it does not call 0x41EDF0. Otherwise it tests DWORD+0x14 bit13 (0x2000); if set, skips. If both permit, invokes **0x41EDF0**, which checks DWORD+0x14 bit12 (0x1000). If bit12 unset, returns without change. If set, it clears bit12 and resolves the player's SIGNED WORD at +0x72: a negative index chooses external fallback object global0x874B94; nonnegative index chooses source array pointer global0x874B90 + `0x2A8*index`. It reads count DWORD+0x1A8 from selected object and decrements by one only when positive, without underflow.
