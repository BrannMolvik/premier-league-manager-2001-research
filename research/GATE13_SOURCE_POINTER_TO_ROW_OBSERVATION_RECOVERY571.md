## Recovery571 original optional global input observers are NOT passive

The original SHA-verified `footballmanager.exe` native `0x64F7A0` accepted-input path has more effects than the source model's row bit0x10/bit15. At `0x64F7E1` it optionally invokes an owner interface held in global **`0x984810`** via native virtual dispatch, before pressing control bit0x10; the exact concrete target and transitive consequences depend on runtime global object identity and are not established. After pressing, source `0x64F80A..0x64F81C` also invokes the original PSupportStart owner callback **vft+0x10** if the bound control ID and second input argument exist; native row IDs8..14 are source-qualified redraw rather than Apply/Cancel. It then checks global **`0x984818`** and **`0x984814`**, conditionally forwarding pointer events to `0x64FB80` and `0x64FB20`.

Those two helpers are **stateful hover/focus-control pointer trackers**, not merely logging. Both demand active bits `[control+0x18]&3==3` and inclusive-min/exclusive-max x/y inside that control's own native rectangle. `0x64FB20` calls the object's virtual **+0x50** to qualify ownership before writing the object into **`[0x984814]`** at `0x64FB59`; it clears that pointer at `0x64FB6D` when the same owner no longer qualifies. `0x64FB80` analogously invokes native virtual **+0x48**, sets global **`[0x984818]`** at `0x64FBB9`, and clears it at `0x64FBCD`. The original `0x64F860` release path also invokes the optional global owner, PSupportStart virtual+0x14 and these two control trackers after clearing pressed bit0x10. Pointer identity, event positions, virtual +0x48/+0x50 targets and actual runtime global object lifetimes must be reconciled before calling this native event fully implemented.

Therefore `project_original_supportstart_observed_pointer_row_input` intentionally requires a **separate observed native callback result**, and asserts only **source-local row state**. It neither instantiates global observer objects nor silently treats their source effects as absent; even a true source-returning callback cannot prove full original GUI/hover equivalence by itself.
