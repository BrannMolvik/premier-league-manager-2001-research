## Original source identity, key producers and bounded semantics

- `League::0x4F4A10` checks `League+0x58` form-prepared cache. On cache miss it loops through source League members at `League+0x34` using count `League+0x38`; calls `0x4F4970` on each club; runs native `qsort` (`0x668DA4`) over pointer entries of width 4 with **form comparator `0x4F4A70`**; then stores `League+0x58=1` and clears League `+0x40 bit0` (the position-ranking prepared state). This is **a distinct Current Form ordering**, not `0x4F45E0` League Position.
- `0x4F4970` resets club source form accumulator `club+0x28=0`, resolves club owner through virtual entry0, gets calendar root via `0x4079D0` (which chooses `0x947AF0` or `0x947AD8` based on `0x403640`), and searches back through `0x615ED0` in a loop limited by **6** iterations. It terminates on missing matching source node. For each source node, its vtable `+0x44` yields one participating/winning club pointer or null: nonnull equal to current club increments accumulator **+3**, nonnull unequal increments **+0**, null increments **+1**. This arithmetic is directly established at `0x4F49C8..0x4F49E9`, not inferred from reconstructed results. The later `0x510A20` call advances search context between iterations.
- The original `0x615ED0` searches day indices backwards from the requested cursor minus schedule base (`0x615ED6..0x615EE3`), traverses `0x615C50`, and respects a conditional flag/path whose class+0x44 bit6 check at `0x615F11..0x615F23` can skip source nodes. Correct filtering of which recorded matches participate and primary-vs-secondary calendar lifetime requires caller/context tracing; **do not present a naive last six Premier League fixtures as proven original Current Form**.
- `0x4F4A70` compares `club+0x28` **descending** and resolves remaining ties by original club short-name **CP1252 byte comparator ascending** via club virtual owner and nested string pointer reads. It returns `0` for fully equal form/name keys; native qsort tie permutation is not source-closed. Unlike League Position comparator `0x4F45E0`, it does not compare played, goal difference, GF or GA before the short name.
