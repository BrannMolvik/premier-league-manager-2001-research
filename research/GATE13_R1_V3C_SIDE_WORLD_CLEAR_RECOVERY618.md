## Continuation: confirmed native end of 0x5127A0 and crucial late selectors

Static original disassembly bounded at the genuine function exit **0x512D67..0x512D70** (restores EDI/ESI/EBP/EBX, local stack and returns with 4 bytes). The subsequent function begins at **0x512D80** and is not part of 0x5127A0; earlier superficial contiguous disassembly could have accidentally attributed its world effects to the rescheduler.

- **0x408030** (called at 0x512B5B and 0x512BEB, one per embedded SideRef) walks signed side+0x294 player count and ushort IDs at +0x244. For each it reads original global player-pool base 0x875640 with index stride **592**, takes ushort player+0xCC and ushort player+0xCE, scores the integer **player+CC + 2 * player+CE**, and retains the **first** strict-greater-than current maximum; initial maximum zero means nonpositive/empty leaves EAX null. Do not replace with a modern highest-skill or uniform chooser.
- **0x4080A0** (called at 0x512C7B and 0x512CF5, one per SideRef) similarly walks the source native roster and returns first player with maximum strictly positive **ushort player+0xCA**, with first tie winning. This is *distinct* from 0x408030 and drives a different owner+0xF4/+0xF6 record and owner+0xE8 bit2 rule.
- 0x512B66..0x512BDE and 0x512BF6..0x512C6C: selected player 0x408030 supplies ushort +CC/+CE scoring and ushort player+4 native identifier. Existing source owner+0xE8 bit4 gates replacement if the 32-bit computed composite does **not exceed** owner+0x102; otherwise source ORs bit4 and writes +0x102 byte with 8-bit **(byte+CE << 1) + byte+CC** and owner+0x104 WORD. Note that original unsigned/byte widths differ between signed/numeric conditions and final byte store; don't conflate the two.
- 0x512C79..0x512CED and 0x512CF3..0x512D67: selected player 0x4080A0 supplies byte +CA and ushort player+4. Source owner+0xE8 bit2 decides if score byte exceeds already recorded owner+0xF4; otherwise sets bit2. Then stores owner+0xF4 byte and owner+0xF6 WORD. First and second sides have distinct virtual getter calls and may mutate owner state between checks and stores; no atomic live state projection until owner identity/reached callback effects are known.
- **0x419490** reached from the pre-search player loop is a high-impact native side-effect function, **not just a condition flag helper**. At 0x4194DA source clears bit1 of player+0x14; conditional competition owner virtuals read the original +0x13E countdown, decrement and potentially produce a 0x48-byte native event through 0x668140 and 0x5853F0; alternate player+0x13B countdown and +0x160/global date path can call 0x585000. The constructed event record at 0x419648..0x41966D uses source global date 0x9847FC, exact event vtable 0x7BD564, ORs 0x06 into constructed owner+8 and inserts with **0x613EC0** into original registry 0x947AA8. This can update event lifecycle/save even when the earlier calendar search missed.
- **0x4197C0** native per-row callback has conditional 0x4085D0; original side context may call 0x417EE0 and 0x41A250/0x41A490; the reached match world path has conditional writes to player+0x13B/+0x13C/+0x160 and invokes original RNG helper **0x64D540** (0x4198C6); false/true branches call 0x419D90/0x419BC0. This invalidates any deterministic “just clear row flag” shortcut.
