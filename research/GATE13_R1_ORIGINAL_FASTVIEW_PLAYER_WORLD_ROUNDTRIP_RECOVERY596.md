## Original per-player writeback: entire reached source boundary

- Original **pre-modal 0x533BF0** visits each of TWO original side pointers (zero-side via match_obj+0, second via match_obj+0x5B0) and reads 20 DWORDs from side club+0x244 into global0x877CF4+side*0xA0 (already integrated PR673). It then reads native **club+0x294 original player count**, visits each player WORD ID at club+0x244+2*ordinal, resolves player through global registry pointer 0x875644 virtual+0 and takes original player record subobject pointer +0x248. It calls source **0x4EA3C0 low five bits of player subobject BYTE+3** and **0x4EA3D0 low four bits of BYTE+4**, writes both values as DWORDs into globals **0x877BB4+side*0xA0+4*ordinal** and **0x877A74+side*0xA0+4*ordinal** respectively. The rest of each 0x140-byte global retains original values; no source evidence for zero fill.
- **Native post-modal 0x533CA0** first copies two club+0x244 80-byte blocks back from 0x877CF4 globals; it then reads source match_obj counts **+0x5A4 / +0xB54** for the two sides, enumerates each player WORD ID at the *updated* original club+0x244+2*ordinal, resolves original player record through 0x875644. For first 11 players it calls **0x4182F0**, which source sets player record DWORD+0x14 bit0x10 then invokes 0x418160, 0x418180, 0x418170 and conditional additional 0x41EDF0. For remaining player indices it calls **0x4182C0**, which sets bit0x20 within DWORD+0x14 after 0x418150 then calls 0x418180, 0x418170 and 0x4EA370; their full transitive world effects remain unresolved.
- Then original 0x533CA0 resolves the **same** player by WORD ID, takes subobject player+0x248, reads **native 32-bit source value from 0x877BB4+side*0xA0+4*ordinal**, invokes 0x4EA330 on subobject; this setter updates ONLY low five bits of subobject BYTE+3, preserving its high three bits. It reads native BYTE from 0x877A74+same stride and calls **0x4EA350**, which updates ONLY low four bits of subobject BYTE+4, preserving the high four bits. These are source-exact `(old & ~mask)|(new & mask)` byte writes. The original 0x533BF0 getters and 0x533CA0 setters are a bounded source roundtrip when the intervening modal changes nothing.
