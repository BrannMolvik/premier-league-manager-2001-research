## Original virtual method ownership of the date collision comparison

Original adjacent date scan `0x615790` (source-audited and merged PR694) calls existing match native vtable+0 **only after** event+8 is null and native v+0x18 payload match+0x44 bit0x40 is clear. Original `0x510A80` is vtable+0 for all 7 authenticated LeagueMatch native classes; vtable+4 for those same classes is original `0x510A40`. All 14 original vtable pointer DWORDs were independently checked in owner-private PE (prior PR694 additionally verified +0x18).

At `0x510A80`, original existing LeagueMatch calls the comparison object's vtable+4 for SideRef `existing+0x14`; if result is nonzero returns1 without the second call; otherwise it calls that v+4 for SideRef `existing+0x28` and returns Boolean result. At `0x510A40`, comparison LeagueMatch invokes `0x4F2830` on its SideRef at `comparison+0x14` with the incoming existing SideRef, short-circuits success, then tests its second SideRef at `comparison+0x28` the same way. This is original virtual dispatch, not simply set-intersection of club IDs.

Original `0x4F2830` calls left SideRef's native virtual+0 getter at `0x4F2836`. If getter EAX nonzero, it **also** calls right SideRef virtual+0 at `0x4F2842`, then compares **left SideRef cached DWORD+0x04 AFTER getter** against **right getter's returned EAX**, not against left getter EAX. This matters if the getter's returned pointer differs from previously cached field, or the getter changes the source SideRef state. If left getter returns zero, `0x4F285D` calls right getter; right EAX nonzero yields false immediately. Only if **both** source getters returned zero does `0x4F286A..0x4F289B` compare source literal (WORD+0x0C type, DWORD+0x08 original owner pointer, WORD+0x0E selector), in that source order. The native getters can be mutating competition selectors and club caches; the present `CupClubRefDescriptor` and `PrimaryScheduleShadowEntry.side_club_cache` do not yet supply fully source-executed getter results or full original pointer identity.

**Independent private static evidence:** `0x4F2836/42/44/49/5D/6A/6E/7B/7E/8C/92` plus native `0x510A4C/63/90/9F`, **15/15 native original PE opcode sites** were checked directly. No binary executed.
