Its language initialization instruction at `0x6379FD` is ordinal **200**; original IDX[200] = string 19781 = **`Football Club`**. Native composite string is `<T+P>%s<T-> @ <T+C>%s %s<T->` (at `0x833318`). Club's dynamic `0x403600` naming branch and exact displayed text source are **not** yet qualified for all clubs; therefore the row **must not yet infer its positive player+club label** from generic `club_id`.
- Native `PMessageRow` at `0x471F3E` reads global `0x981DA4` for its date template; language initialization ordinal **2709** maps IDX[2709] = string 21852 = **`%D/%M/%Yf`**. Original formatter `0x64D150` uses its native tokens, **not** POSIX/Windows strftime directives: `%D` outputs unpadded decimal day; `%M` copies exactly the first three CP1252 bytes of the full native month name; `%Yf` formats the four-digit year (1900 + native offset). The month pointer array at `0x84A030` through `0x64D140` maps January..December to IDX ordinals **125..136** (STR 19718..19729), verified as the shipped month names. For 1 August 2000, the source output is **`1/Aug/2000`**, not guessed ISO or `08/01`.
