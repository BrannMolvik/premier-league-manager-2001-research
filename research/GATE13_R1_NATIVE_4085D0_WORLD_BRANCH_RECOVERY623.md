## Source call owner and read-only branch classification

- Original native `0x4197C0` reaches team method `0x4085D0` only if its **second per-row argument EBP is nonzero** and player+0x14 bit4 is clear. The parent code derives team from signed current player+0x10 (negative original global fallback `0x874B94`, else `0x874B90+680×index`) and calls `0x4085D0` with player pointer and two zero arguments. The direct `0x4085D0` early return-1 branch can occur for other callers but is unreachable from that particular parent because its bit4 condition is inverted.
- At `0x4085DF` source calls `0x417EE0` with current player and **team owner DWORD+4**. Native 417EE0 compares signed WORD player+0x10 with team+4; if equal returns player+0x14 bit4 as 0/1, otherwise zero. A true result immediately returns `0x4085D0 EAX=1` with no writes/callbacks.
- Otherwise native `0x407060` walks signed team roster count +0x294 over uint16 IDs at +0x244, resolves source native players from global `0x875640` at stride **592** and invokes read-only `0x41FAB0` per player with owner-context and filter code4. It counts eligible non-target teammates having player+0x14 bit4 set. A returned count **>=11** makes `0x4085D0` return zero before category access, without world writes.
- With count below 11, source reads player pointer+0x248 and `0x4EA3C0` extracts **(object BYTE+3 & 0x1F)**. `0x406BE0` counts other eligible team members sharing the reached category (through its source 0x417EE0 and `0x4EA3C0` reads). `0x5F0D20` reads original `0x87AE64` category capacity registry through original 0x24-byte records terminated by category 1000; returns **max recorded bound +1** for matching category. If peer count is at least capacity, source returns zero with no writes.
- When peer count is **strictly below** that returned category capacity, original `0x408636` calls **0x4182F0** and then `0x408644` calls **0x4EA350**. These are real player/world mutations, not a harmless selection predicate, and are not equivalent to a generic modern injury/suspension toggle.
