## Source-verified 0x405080 roster count, avoiding invented return values

Source native `0x405080` reads team signed roster count at team+0x294, uint16 native player IDs at team+0x244 (40 slots), then dereferences original global `0x875640` player-array base using explicit **592×ID** arithmetic (actual original `LEA ID×9 → ID×37 → <<4`), which is different from the dynamic vtable getter used in `0x5127A0`. For each reached source DBRPlayer, tests status DWORD+0x14 bit **8, 0, 6, 1** and subtracts one from eligible count if any is set. Zero-count skips the global array base and returns zero. Invalid counts, out-of-range pointer calculations and unmatched original player+4 ID fail closed. The original initial `0x405080` loop is read-only. A reached original 405080 count can be independently cross-checked against a typed source receipt; mismatched team owner, result and even current post-row player's +0x14 status are rejected.
