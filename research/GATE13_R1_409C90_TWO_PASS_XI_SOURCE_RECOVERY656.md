## Critical semantic correction to PR769

Original `409D5E` writes native `418130` or `418050` AL per ordered roster player into an allocated temporary BYTE mask. The earlier PR769 helper returned the bytes correctly but labeled the result “availability.” **This is a native EXCLUSION/skip mask, not a positive selectable-player list:** original `409DDA` tests the mask; `409DDC` jumps to the next player when the byte is **nonzero**. Independently, original `409DE2/409DE5` skips if the first mutable *used* array is nonzero. A selected player is marked 1 in the used array at `409EF0`, and the second pass also tests both nonzero exclusion/used bytes at `409FD8/409FDE`. Never interpret source `418050` AL1 as “ready to be selected” in a reconstructed real XI. This source correction is recorded here and reflected in both new implementations; future live GameState eligibility must honor the actual original consumer.

## Original first pass, strict role matching (409D79..409F5E)

Native `409C9A` sets ESI=0, `409CA6` stores that zero in the special-count local at ESP+14 after stack changes, and `409CF7` writes source modeflag0 when the native team+74 class is 2 or3; modeflag can otherwise be an independently set caller value. At `409D79`, original iterates **11** formation role slots. For each in original team+244 WORD roster order:

1. Skip if original initial mask byte !=0 or prior selected/used byte !=0.
2. If player DWORD+14 bit11, original `41B490` calls source `407DF0(team)`. Native `409E09` **unsigned JAE** skips when the current special count is >= original returned EAX. Non-bit11 players do not invoke that gate.
3. For a remaining player, exact formation-role DWORD is sourced from original `876CB8[(formation*11+slot)*8]`, with full eight-byte role record provenance. Original calls `4EA300(0)`, then if needed `4EA300(1)`, then if needed `4EA300(2)` on separate native player+248 status. Only a matching role byte reaches scorer.
4. On a role match, original `41C7E0(player,role)` returns a signed EAX; original `41B970(player)` returns an x87 factor; `668350` truncates the source x87 product to signed EAX, and only exact zero becomes 1. The worker does **not** infer any of these dynamic outcomes from prototype player ratings: the bounded projection requires independently reached actual `41C7E0` and `668350` results, refuses guessed/unreached outcomes. Best initially 0; native `409E8F JLE` means only score strictly **greater** replaces the selected index. Original tie preserves earlier scanned roster index; negative scores need not be selected.
5. At `409EF0/409EFE`, native writes the winning roster INDEX into the output slot and sets that player's used mask byte=1. If player bit11 and original modeflag1, original tests source `874BE0` indexed WORD and increments special count only on nonzero.

## Original second pass, fallback role filling and retry (409F74..40A158)

Original iterates the same 11 formation output positions. If an output slot is already nonnegative, jump over all second-pass candidate callbacks for that slot. For an empty slot (DWORD -1):
- Scan every ordered original roster WORD ID excluding source nonzero initial mask and already-used byte, and skip source `407DF0` unsigned cutoff for bit11 players.
- **Do not use 4EA300 role-matching at all** in this fallback pass. Call actual original `41C7E0(player, slot role)`, `41B970`, and `668350` on each reached unexcluded player. Zero→1, strict positive-best comparison and earlier tie handling remain, then write source selected roster index and mark used.
