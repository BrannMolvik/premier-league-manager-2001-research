## Bounded original evidence, including what is **not** known

The original `PFormation2k` panel is identified by prior first-hand original-executable/RTTI analysis, vtable **`0x7C1AB4`**. The original `DBRUser` serialized region **`+0x70C..+0x10D7`** has size **`0x9CC`** and a **`0x074A3216`** magic/header; original formation/team-sheet records begin at **`+0x714`**, with exactly **five** records of **`0x1F4` bytes**. That sums to 8+5×500 = 2,508 bytes = 0x9CC. Source record contents include saved formation/team-sheet names, player identifiers and assigned-role data. This is documented in `research/GATE13_TACTICS_PRESENTATION_CONTRACT.md` and already projected *as metadata* by `reconstruction/gate13_management_source_data.py::TACTICS_PRESENTATION_CONTRACT` (formation record count5, size0x1F4, original offsets and magic).

**Important limitation:** this establishes five native serialized data records associated with `PFormation2k`, **not** their on-screen controls, whether/how the five are edited or activated, which source record the live match engine consumes, or an original native save-file byte codec. Do not claim a five-button UI or exact slot semantics from this header alone. The original root executable identity was previously verified as 4,714,541 bytes / SHA256 `833bf95e92a1c76ade47106f8ad7d3ca307069b7e5778a7067cd0658838b7cc3`; a trivial local shell command still returns `caas.internal.errors.ClientError`, so the original source was **not freshly rehashed or disassembled** here.
