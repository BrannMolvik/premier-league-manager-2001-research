## Actual source of 510CD0 chosen pointers

Native `510CD0` iterates original team+294 signed count, ordered team+244 WORD IDs, and global `875640 + WORD_ID × 0x250` native base player records. It invokes `417F50(player, original team pointer)` at 510D11. Source `417F50` reads team DWORD+4 and calls `417EE0`: source player's signed WORD+10 **full 32-bit sign-extended comparison** against that club key, then source player's DWORD+14 **bit4**. When true, it appends the player's **base record pointer**, exactly once, to context target buffer; it does **not** call 417F60 on this player. When 417F50 returns false, original `510CD0` invokes **417F60** at 510D1D on the same player and actual original team; it similarly reads source team+4 but checks original `417F00`, which tests source player's **DWORD+14 bit5**, with the same signed WORD+10 owner equality. It appends a pointer when either flag succeeds, so bit4 AND bit5 both true still results in **one pointer**, not two. Return EAX is actual number of pointer records appended. Below/at zero roster count returns zero and no source selection is reached.
