# Original FM2001 Assets

This directory is reserved for **authorized original FM2001 resources intentionally reused by the Windows 11 modernization/port**.

The project owner has confirmed authorization to use the contents of the supplied source archive/disc image.

## Rules

- Prefer original resources over unnecessary recreations.
- Keep imported source resources under this directory.
- Keep raw full-disc images and temporary extraction dumps out of Git.
- Record provenance in `MANIFEST.md` as assets are added.
- Put converted/modernized derivatives under a clearly named subdirectory such as `converted/`.
- Do not mix executable replacement code into this directory.

See `research/ASSET_POLICY.md` for the full policy.

No original binary assets have been added by this documentation commit.
